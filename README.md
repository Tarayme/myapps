# Roleplay AI (Android MVP)

Native Android MVP for adult-only AI roleplay chat.

Features:
- 18+ age gate
- Character creation and deletion
- Per-character persistent chat history
- Configurable OpenRouter chat model
- OpenRouter image generation from recent scene context
- API key encrypted with Android Keystore before local storage
- GitHub Actions debug APK build

Important: this MVP is BYOK for personal testing. A production/public build should move provider keys and abuse controls behind a backend proxy.
