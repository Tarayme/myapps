# PrivateRoom Android prototype

Installable Android prototype for the paid private video-room concept.

Current APK prototype flow:
- Live creator list
- Creator profile
- Green private-room invitation
- Waiting / accept simulation
- Private-call timer
- Gift picker
- Call summary
- Creator earnings dashboard

The UI is native Android and intentionally uses no third-party runtime dependencies.

The actual LiveKit/Supabase backend from the earlier scaffold can be connected after the interaction design is approved.
